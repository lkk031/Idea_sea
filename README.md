# 灵感海 · IDEA SEA

一片只给自己看的浅蓝海域。把还没发生的念头丢进水里，它们会自己慢慢漂动、互相碰撞；完成了，就让它出海。

支持桌面浏览器、手机浏览器和 Android App。桌面上会以一台独立的手机画框呈现，手机上则全屏显示。

当前发布版本为 **v1.0**（应用版本 **1.0.0**）。从 [GitHub Releases](https://github.com/lkk031/Idea_sea/releases/tag/v1.0) 下载已签名的 Android 安装包及 SHA-256 校验文件。

## 本地运行

```bash
npm install
npm run dev
```

默认打开 `http://127.0.0.1:5173/`。

物理回归检查（局部凹陷、不对称鼓包、文字避让、贴墙、快速拖拽、平滑回弹、移动接触点、密集碰撞、高刷新率插值及减弱动态效果）：

```bash
npm test
```

生产构建：

```bash
npm run build
npm run preview
```

## 怎么用

- **收进来**：在底部输入一句想做的事，按 `Enter` 或点右侧圆形按钮。念头会裹成一颗深蓝色水珠，沿弧线越过水面落进海里，化成一枚海玻璃泡泡。
- **让它们动起来**：每颗泡泡都会带着轻微速度和方向在海底漂浮，碰到边界会反弹，碰到彼此会挤压、减速、改向，并轻轻“弹”一下。
- **拖一拖**：按住泡泡拖动时，它会暂时被抓住，推开周围其他泡泡；松手后会带着甩出的速度继续漂。
- **去完成**：按住泡泡向上拖，越过水面后松手。水面会绽开金色涟漪、光柱和星屑，泡泡出海消失。
- **删除**：轻点泡泡后它会被暂时定住，右上角出现 `×`；点击后泡泡溶解沉入海底。
- **撤回**：完成或删除后的 5 秒内，底部浮出的信息条上可以点“撤回”，把念头捞回来。
- **键盘**：`Enter` 选中泡泡；选中后再按 `Enter` 完成；`Delete` / `Backspace` 删除；`Esc` 收起。

首次打开会带 5 条示例念头，直接删掉即可开始自己的海。数据只存在浏览器 `localStorage` 里，不上传。

重置 demo（会重新带出示例念头）：

```js
localStorage.removeItem("idea-sea.v1");
localStorage.removeItem("idea-sea.gesture.v1");
location.reload();
```

存储键：`idea-sea.v1`（念头）、`idea-sea.gesture.v1`（新手手势提示是否看过）。

## 设计说明

- **浅海蓝**：天空是接近白色的雾蓝，水体从浅青蓝过渡到深海蓝；泡泡是乳白、贝壳、奶油、玫瑰、雾紫的海玻璃。细小焦散、漂浮微粒、水面反光和底部深色暗部共同撑起水下层次。
- **会呼吸的海**：每颗念头有单独的漂浮速度、方向和微小的洋流加速度。物理保持 120Hz，显示时同步插值位置和轮廓，让 90Hz、144Hz、165Hz 屏幕也能连续过渡。每帧直接更新 DOM 的 `translate3d`，不让 React 参与物理帧；文字布局只在尺寸变化时测量，轮廓与文字变换仅在变化时写入。
- **柔和挤压**：轻碰只产生浅而宽的局部凹陷，持续推挤才逐渐加深，周边只有小幅圆润隆起。受力随碰撞速度平滑增长并饱和，整体拉伸受到严格限制，避免轻碰后突然瘪扁或长出尖鼓包。接触区的位置按受压范围加权计算，多个接触点共同施压时不依赖处理顺序；接近临界阻尼的弹簧让轮廓柔和恢复，并减弱碰撞后的弹开速度。
- **碰撞**：每颗物块的轮廓由 24 段独立弹簧控制。接触点局部凹陷，周围形成大小不同的鼓包；弹性和阻尼随材质位置略有差异，回弹会沿边缘传递，避免整块对称缩放。SVG 绘制与碰撞采样共用同一条平滑曲线，凹陷处可以真实容纳相邻物块；轮廓保持约 2px 接触间隙，并补偿受压造成的面积变化。物理以 120Hz 固定步长运行，连续推挤会维持受压，贴墙沿空余方向滑开。文字根据轮廓内部空间缩小、偏移，避免伸出边缘。系统切换至减弱动态效果时会立即清除表面波动，并保留手动拖拽与碰撞。
- **动画**：Motion 弹簧 + 关键帧。收纳用弧线飞行、深色水珠和光尾；完成用顶部金色爆闪、水面环、光柱和星屑；删除用失焦收缩和下沉微粒。尊重系统的“减弱动态效果”设置——此时物理漂浮会静止，只保留手动拖拽。
- **无多余功能**：没有账号、分类、云同步、完成历史、统计、设置。只有一个闭环：放进海里 → 自由漂浮/碰撞 → 完成后划出或删除。

## 安卓 App · v1.0

安卓工程位于 `android/`，使用 Capacitor 8.5.3 加载随 APK 一起打包的网页资源。
不依赖开发服务器，离线可用。
应用名称为“灵感海”，包名 `com.ideasea.app`，最低 Android 7.0，目标 Android 16。

构建需准备 Node.js 22+、JDK 21、Android SDK Platform 36 和 Build-Tools 35.0.0，
设置 `JAVA_HOME`、`ANDROID_HOME`，再执行 `npm ci`。

```powershell
# 构建已签名的正式 APK
npm run android:build

# 构建、覆盖安装到已连接且已允许 USB 调试的手机，并启动
npm run android:install

# 有多台设备时指定序列号
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/android.ps1 -Install -Serial <设备序列号>
```

正式安装包输出到 `artifacts/android/idea-sea-1.0.0-release.apk`，旁边附 SHA-256 校验文件。
签名密钥与密码保存在被 Git 忽略的 `.android-signing/`，请私下备份整个目录；
后续更新必须使用同一密钥和包名，才能覆盖安装并保留数据。不要公开这个目录。
修改应用版本时同步增加 `android/app/build.gradle` 中的 `versionCode`。

App 数据独立保存在手机的应用空间，浏览器原有的 localStorage 不会自动迁移。
同签名覆盖安装会保留数据；卸载 App 或清除应用数据会删除本地念头。

已在 vivo S20 Pro（Android 15）验证启动、中文输入、软键盘避让、新增、删除、撤回、
拖出水面完成、强制关闭后的持久化，以及关闭网络并跳过缓存后的重载。
现有 29 项回归测试全部通过；正式包通过 Android 发布检查及 APK 签名校验。

### v1.0 手机端修复

- 键盘出现时原生画布和海域保持原尺寸，只有输入栏避让；已有灵感继续沿原轨迹运行，包括键盘遮挡区域。
- 用渐变软边和阴影替换手机上的多层模糊滤镜，保留物块轮廓、内部渐变和挤压动作，改善白屏及整组灵感块闪烁。
- 为拥挤时的碰撞求解和慢帧追赶设置预算，停止重复求解无法改善的冲突，避免持续拖慢输入与动画。

在 vivo S20 Pro（Android 15）上使用 8 个最长文字块、12 个普通块，以及连续挤压、输入、完成、删除进行验证。本轮录像未再捕获整组消失，收起键盘后能恢复正常帧率；密集场景切换键盘或拖出完成时仍可能短暂掉帧。海域过满时仍可能出现重叠，计算预算不等于无限容量。
